# Project instructions

## Preserve animations and visual effects

- Preserve existing animations and visual effects by default.
- Before removing, disabling, hiding, or replacing an animation or visual effect, ask the user for approval unless the user's prompt or prior explicit direction already authorizes that specific removal.
- Refactoring, performance work, cleanup, and bug fixes do not by themselves authorize removing an animation or effect. Explain the proposed removal and obtain approval first.
- Continue other authorized work while awaiting that approval.
