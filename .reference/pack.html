About

Metre-scale highway freight collection with named wheel and coupling pivots, documented kingpin assemblies, and complete truck-stop demonstration. Wheels, cab doors and trailer rear doors carry clips as rigid node transforms; no skinning. CC0.

Files load directly from the CDN. Choose the pieces you need. Colliders, navigation and gameplay scripts are supplied by your game.

Which game engines and tools can I use Long-Haul Trucking and Truck Stop with?
Anything that reads glTF, which today means all of the major ones: three.js and React Three Fiber on the web, Godot 4, Unity, Unreal Engine 5, Blender and the model-viewer web component. Every model in the pack is a self-contained binary glTF (.glb) with textures embedded, and so is the starter scene, so each is one file to import and no plugin, converter or decoder to install first.
How do I import this pack into Unity, Godot, Unreal or Blender?
Unity: install the glTFast package (com.unity.cloud.gltfast) from the Package Manager, drop the .glb into Assets and drag the prefab in, or load it at runtime from the CDN URL. Godot 4: copy the file into the project folder and the editor imports it as a scene you can instantiate. Unreal Engine 5: File > Import with the built-in glTF importer, which converts the axes for you. Blender: File > Import > glTF 2.0. Units are metres with +Y up in the file, and every importer above handles the conversion to its own axes automatically.
Can I use Long-Haul Trucking and Truck Stop in a commercial game, and do I need to credit anyone?
Yes to commercial use and no to credit. Every pack on 3DAssets.dev is released under CC0 1.0 Universal, which places it in the public domain: use it in a paid game, an app, a film or a client project, modify it, redistribute it, and put nothing in the credits. A link back is welcome but it is entirely your choice.

Can I load it from the CDN instead of downloading it?
Yes. The starter scene, one .glb with every piece placed, has a permanent URL on cdn.3dassets.dev that is CORS-enabled and never changes content, so you can pass it straight to GLTFLoader, glTFast or model-viewer in production and cache it as hard as you like. Downloading is only needed for engines that import from disk.
Do I have to download the whole pack?
No. Every model in the pack is a separate published asset with its own download and CDN URL, so you can take one prop or the entire set. The starter scene is the one-file option for people who want everything placed at once.
Do the models in Long-Haul Trucking and Truck Stop fit together?
That is the point of a pack. The members are built together to one real-world scale with consistent pivots and a shared palette and level of detail, so a building, a vehicle and a prop from the same pack sit correctly in one scene without rescaling or re-texturing.
